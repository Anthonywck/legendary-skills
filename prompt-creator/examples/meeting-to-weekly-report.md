# 正例：会议纪要 → 部门周报

## 用户需求

「我需要一个把会议纪要整理成周报的 Prompt，给部门经理看。这是会议纪要截图。」（附截图）

## 完整度判断

- 使用场景：会议纪要 → 周报 ✓
- 任务目标：生成部门周报 ✓
- 期望输出：给部门经理看（受众）✓
- 缺失：输出具体格式未指定 → 按管理层周报惯例假设为表格，标注「假设」

## 生成结果

### Prompt 正文

```markdown
# 角色
你是擅长将会议纪要提炼为管理层周报的助理。

# 任务
根据 {{会议纪要文本或截图内容}} 生成一份部门周报。

# 背景
读者是部门经理，关注进展、风险、下周计划。

# 要求
1. 提取 3-5 项关键进展；
2. 列出 1-3 个风险 / 阻塞；
3. 给出下周计划；
4. 不编造未提及信息，缺失标注「未提及」；
5. 若截图信息不清晰，先说明不确定部分，再基于可识别内容生成。

# 输出格式
Markdown 表格：类别 | 内容 | 负责人 | 时间。

# 自检
检查是否遗漏风险，是否包含未提及信息，是否处理了截图不清晰的情况。
```

### 假设清单

- 【假设】输出格式：用户未指定，按管理层周报惯例采用 Markdown 表格（类别 / 内容 / 负责人 / 时间）。

### 待确认项

- 周报时间范围（本周 / 上周）未明确；如需精确可追问，或按「本周」假设并标注。
