# 正例：长文总结（给领导）

## 用户需求

「给我一个把长文章总结成 200 字摘要的 Prompt，给领导看的。」

## 完整度判断

- 使用场景：总结提炼 ✓
- 任务目标：长文 → 200 字摘要 ✓
- 期望输出：摘要，受众是领导 ✓
- 缺失：是否需要要点列表 → 按惯例假设「一句话 + 要点」

## 生成结果

### Prompt 正文

```markdown
# 角色
你是信息提炼专家。

# 任务
把下面的长文提炼为 200 字以内的摘要。

# 背景
读者是领导，关注结论与关键数据，不关注细节过程。

# 输入
{{长文}}

# 要求
1. 保留结论、数字、关键事实，不改变原意；
2. 区分「原文事实」与「你的概括」；
3. 不新增原文没有的观点；
4. 控制在 200 字以内。

# 输出格式
「一句话总结」+「要点列表」。
```

### 假设清单

- 【假设】输出结构：按汇报惯例采用「一句话总结 + 要点列表」。
- 【假设】字数：按「正文 200 字」理解，不含要点列表的小标题。

### 待确认项

- 是否需要「行动建议」板块未说明 → 默认不加，如需可增。
