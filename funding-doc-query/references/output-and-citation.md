# 输出与引用

## 一、引用 ID 规则

| 规则 | 说明 |
| --- | --- |
| 编号 | `[S1]` `[S2]` …，从 1 连续，不复用 |
| 粒度 | 一份产物一个 ID；同一产物的不同区段不另编号 |
| 多源 | `[S1][S3]` 并列，中间不加空格 |
| 位置 | 紧跟在被支撑的陈述后，放句末标点前 |
| 定量 | 无 `[S#]` 的数值陈述一律视为违规 |

**判定示例**

```
✅ 森国科 D 轮投后估值 10.2 亿元 [S1]。
✅ 该主体另有两轮融资记录 [S1][S2]。
❌ 森国科投后估值约 10 亿元。          ← 无 ID + 擅自改精度
❌ 半导体赛道普遍估值 10 亿左右 [S1]。  ← 「普遍」是 [S1] 支撑不了的推论
```

**「推断」的写法**：定性判断必须显式标注，并给依据。

```
本次仅有 BP 一份，未找到审计报告 [S1]；据其自述营收增长较快 [S1]，
对财务质量的判断为**推断**，依据是有无第三方审计文件，而非数值本身。
```

## 二、A · 精准问答模板

```markdown
## 结论
（一句话直接回答，含关键数值与 [S#]；无法给出则明说原因）

## 依据
1. {论断} —— [S1]
2. {论断} —— [S2][S3]

## 冲突与不确定
- {指标}：文档 A 为 X（[S1]，{日期}，{date_source}）；文档 B 为 Y（[S2]，{日期}，{date_source}）。
  口径差异：{投前/投后 | 币种 | 单位 | 统计年份}。**未择一，请确认口径。**
- {指标}：`key_facts` 记为 X [S1]，但原文片段为「…」，P3 核验不通过，**未核实**。

（无冲突且全部核实通过时，写「无」并说明「全部 N 条数值已通过 P3 核验」。）

## 来源清单
| 编号 | 产物路径 | 主体 | 文档日期（来源） | 关键事实 | 原始文件 |

## 检索覆盖
- 检索路径：{glob}
- 关键词：{…}；命中 N 份，实读 M 份
- 未纳入：{文件}（原因：超预算 / needs_ocr / duplicate_of / 无相关段落）
```

## 三、B · 知识文档生成模板

```markdown
# {主题}

> 生成依据：`datas-md/by_topic` 检索结果；本文档不构成知识库的一部分，不参与后续检索。

## 摘要
（3–5 句，每句带 [S#]）

## {章节}
（按主题组织；每段事实性陈述带 [S#]；推断处显式标注）

## 外部来源（仅联网时出现，独立分区）
（每条：结论 | 来源标题 | URL | 抓取日期 | 与本地内容关系）

## 来源报告

### 一、引用章节映射   ← 用户核对的主入口
| 编号 | 出现在本文档章节 | 产物路径 | 主体 | 赛道 | 文档日期 | 日期来源 | 原始文件 |

### 二、原文片段（逐字摘录）
| 编号 | 对应字段/论断 | 原文片段 | 所在区段 |

### 三、外部来源（仅联网时）
| 编号 | 出现章节 | 标题 | URL | 抓取日期 | 关系 | 交叉印证状态 |

### 四、检索覆盖报告
- 检索路径与关键词、命中与实读数量
- 未命中项与尝试过的路径
- 未纳入的候选及原因

### 五、可信度与冲突
| 论断 | 已核实 / 未核实 | 涉及来源 | 处理方式 |
```

### 报告硬要求

1. **每条引用都能指回「出现在本文档哪一节」**——`一、引用章节映射` 是入口，
   不能让用户自己去正文里找。
2. **原文片段逐字摘录**，不改写、不省略到失去语义、不「整理成通顺句子」。
3. **外部来源与本地来源物理分区**——报告第三节单列，正文也单独成节。

### 落盘

```
datas-generator/{主题}.md          # 生成文档
datas-generator/qa/{日期}_{主题}.md # 问答留档（可选，用户要求时）
```

目录不存在则创建。**写入前先确认目标路径在 `datas-generator/` 之内**，
任何指向 `datas/` 或 `datas-md/` 的写入请求一律拒绝。

## 四、来源清单字段说明

| 字段 | 取值来源 | 为什么要有 |
| --- | --- | --- |
| 编号 | 本次检索分配 | 正文与报告的唯一连接 |
| 产物路径 | 相对项目根，`by_topic/…` 起 | 用户可直接打开 |
| 主体 | frontmatter `subject` | 判断命中的是不是目标主体 |
| 文档日期 | frontmatter `date` + `date_source` | 用户判断时效与可信度 |
| 关键事实 | 本次引用到的具体条目，**只列引用了的** | 避免整份 dump |
| 原始文件 | frontmatter `source_path` | **反查原件的钥匙**，用户核对最终依据 |
