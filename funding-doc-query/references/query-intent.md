# 意图分流与检索类型

## 一、三类意图

| 意图 | 判定信号 | 输出 |
| --- | --- | --- |
| **精准问答** | 问句指向**单一或有限个可枚举答案**；期望一条结论 | 问答模板（`output-and-citation.md` A 节） |
| **知识文档生成** | 出现「整理 / 汇总 / 生成 / 写一份 / 做一份 / 报告」；期望**文档形态产物** | 文档模板（`output-and-citation.md` B 节） |
| **模糊** | 两者皆可，或缺失关键约束 | 一轮 ≤3 问后重判 |

### 分流判定表

| 用户原话 | 判定 | 理由 |
| --- | --- | --- |
| 森国科的估值是多少 | 精准问答 | 单主体单指标 |
| 森国科投后估值多少、哪一轮 | 精准问答 | 仍是有限字段 |
| 帮我整理森国科的融资历史 | **模糊** | 可以是表格答案，也可以是文档 |
| 把森国科、云潼科技做个对比 | 精准问答（比较型） | 答案有限，表格即可 |
| 半导体赛道有哪些公司做过 SiC | 精准问答（聚合型） | 答案是清单 |
| 写一份半导体赛道 SiC 融资概览 | 知识文档生成 | 明确要文档 |
| 这家公司怎么样 | 模糊 | 主体不明、维度不明、形态不明 |
| 帮我看看这些文件 | 模糊 | 无检索对象 |

**判定口径**：产物是「一段可粘贴的答案」→ 问答；产物是「一份可存档的文档」→ 生成。
「组织成表格」仍属问答，不构成文档。

## 二、模糊时的追问（一轮 ≤3 问，不得多轮）

只问**会改变检索动作**的问题，优先顺序固定：

| 优先级 | 问题 | 为什么必须问 |
| --- | --- | --- |
| ① 产物形态 | 「你要一个直接回答，还是一份可存档的文档？」 | 决定输出模板与是否落盘 |
| ② 范围 | 「只查这一家，还是要把同赛道同类公司一起列？」+「时间上有没有起止？」 | 决定 glob 范围与 read 份数 |
| ③ 联网 | 「库内如果没有，要不要我去查外部信息？」 | 联网默认关闭，必须显式授权 |

**不问的东西**（能从库里自己找到，问了只是拖延）：

- 「你说的森国科是哪家？」——先做别名解析，解析到唯一主体就不要问
- 「你要看哪一年？」——先按时间权重排序再呈递，让用户从结果里收窄
- 「字段名是不是投后估值？」——库里字段名固定，直接按 `field-map.yaml` 映射

### 追问模板

```
在开始检索前，我需要确认 3 件事：
1. 产物形态：要直接回答，还是一份可存档的文档？
2. 范围：只查 X，还是需要连同 <同赛道/同类型> 一起列？时间范围有要求吗？
3. 若知识库未收录：是否允许我去检索外部公开信息？（默认不联网）
```

## 三、五类检索类型

| 类型 | 识别 | 典型问法 | 检索动作 | 常见陷阱 |
| --- | --- | --- | --- | --- |
| **点查** | 单主体 + 单字段 | 「X 的投后估值」 | P1 命中 → P3 回查 | `key_facts` 值有单位错误，必须 P3 |
| **比较** | ≥2 主体 + 同一维度 | 「X 和 Y 谁估值高」 | 分别点查后并列 | 单位不统一（亿 / 万元）不可直接比 |
| **聚合** | 「有哪些 / 都谁 / 清单」 | 「哪些公司做过 SiC」 | glob 定范围 → P1 批量筛 → 覆盖报告 | 只答「我读到的几份」而漏报覆盖范围 |
| **时间演进** | 「变化 / 历史 / 最新」 | 「X 估值怎么变的」 | 同 `entity_key` 全量取 → 按权重排序 | 用 `fs_mtime` 当时间线 |
| **缺失确认** | 「有没有 / 是否收录」 | 「库里有 X 吗」 | 穷尽 glob + grep → 未收录输出 | 命中同名干扰项后误判「有」 |

## 四、查询解析产出（Step 1 的固定格式）

检索前先把问题拆成这五项，写进覆盖报告；缺项写「不限」：

```
赛道：半导体
主体：森国科（用户口语）→ 待解析
doc_type：BP（推断：融资数据只在 BP 中有）
时间范围：不限
概念词：估值 / 投后估值 / valuation
检索类型：点查
```

**概念词扩展**：中文库里同一概念常有多种写法，检索时必须并查。
常见映射见 `assets/field-map.yaml`；用户用英文或缩写时，同时用中文原词 grep
（例：`SiC` 与 `碳化硅` 必须并查，实测库内两者分布不均）。
