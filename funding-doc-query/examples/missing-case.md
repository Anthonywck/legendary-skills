# 正例 · 未收录的正向回答

> 演示：「没有」也是答案，且必须是有信息量的答案——说清搜了什么、为什么没搜到。

## 用户问题

> 知识库里晶湛半导体（GaN 外延材料公司）的估值是多少？

## Step 0 · 意图判定

精准问答（缺失确认）。不追问。

## Step 1 · 查询解析

```
赛道：不限（不确定在哪个赛道，先全库）
主体：晶湛半导体
doc_type：不限
时间范围：不限
概念词：估值
检索类型：缺失确认
```

## Step 2–3 · 穷尽检索

**别名变体逐条尝试**（按 `retrieval-playbook.md` 的降级顺序）：

| 序 | 关键词 | 范围 | 命中 |
| --- | --- | --- | --- |
| ① | 用户原词 `晶湛半导体` | `datas-md/by_topic/**/*.md`（172 份） | **0** |
| ② | 去地域/后缀 `晶湛` | 同上 | **0** |
| ③ | 英文 `Enkris` / `Crystal` + GaN | 同上 | 0（与主体无关，命中的是别家 GaN 项目） |
| ④ | entity_key 归一化 `jingzhan` | 同上 | **0** |
| ⑤ | alias_pinyin | — | **本步跳过**：全库 172 份 `alias_pinyin` 均为 `null` |

**降级漏检排查**：

| 降级产物 | 是否可能含该主体 |
| --- | --- |
| `半导体/2026/REPORT/2026-07-28_REPORT_沙利文_v1.0.md`（corrupt） | 标题为「石英坩埚行业研究」，与 GaN 外延无关 |
| `节能环保/2023/BP/2023-07-08_BP_纤尘不染_v1.0.md`（empty） | 空气取水，无关 |
| 另外 3 份 `encoding_error` | 主体为「中博芯」「碳化硅芯片及模块」「苏州错威特」，均非晶湛 |

结论：降级文件共 5 份，主题均不匹配，**不构成漏检怀疑**。
（当前快照 `needs_ocr` 为 0 份；若后续有新扫描件入库，需重做本步。）

## Step 5 · 输出

```markdown
## 结论
**知识库未收录「晶湛半导体」**，因此无法给出估值。

## 检索覆盖
- 检索路径：`datas-md/by_topic/**/*.md`（全库 172 份 `.md`）
- 关键词及命中：
  | 关键词 | 命中 |
  | --- | --- |
  | 晶湛半导体 | 0 |
  | 晶湛 | 0 |
  | jingzhan（entity_key 归一化） | 0 |
  | alias_pinyin | 未执行（全库该字段均为 `null`，路径不存在，非「查过没有」） |
- 命中 0 份，实读 0 份

## 可能漏检的风险
- 库内有 5 份降级产物（1 corrupt / 3 encoding_error / 1 empty），
  其正文不可检索。已逐一核对标题与主体，**均与 GaN 外延材料无关**，
  因此判断漏检可能性低。
- 本库以半导体为主（159/172），若该主体确实属于半导体赛道，未被收录说明它
  不在当前知识库的采集范围内；**这不代表该公司不存在或没有融资**。

## 建议
- 若需该主体数据，请补充对应 BP / 报告原件后由 `funding-doc-structurer` 入库。
- 是否需要检索外部公开信息？**默认不联网**，需你明确同意。
```

## 对照：四种不通过的回答

| 回答 | 为什么不通过 |
| --- | --- |
| 「知识库中没有相关信息。」 | 没说搜了什么，用户无法判断是否搜过 |
| 「晶湛半导体是一家 GaN 外延材料公司，2021 年完成 B 轮融资…」 | 用模型记忆补全，**零臆造一票否决** |
| 「可能有，但是扫描件没 OCR 所以没查到。」 | 未核实降级文件的主题就下结论，把猜测当原因 |
| 「未收录。另外行业里类似公司有 A、B、C…」 | 用户问的是本库有没有，不是行业盘点；越界提供未引用信息 |

## 这个例子演示了什么

| 要点 | 体现 |
| --- | --- |
| 穷尽性 | 4 种别名变体逐条列出，`alias_pinyin` 明确说明为何跳过 |
| 降级排查 | 把 6 份不可检索文件逐一对标题，排除漏检怀疑 |
| 边界清晰 | 区分「本库没有」与「这家公司没有」 |
| 不越界 | 不主动联网，不擅自扩大到行业盘点 |
| 可行动 | 给出补数据的路径（走 structurer 入库） |
