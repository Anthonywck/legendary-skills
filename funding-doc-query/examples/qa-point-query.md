# 正例 · 单主体单指标点查

> 演示：P1 定位 → P3 核验 → 冲突提示 → 覆盖报告。
> 所有路径与数值均可在 `datas-md/by_topic` 复核。

## 用户问题

> 森国科的投后估值是多少？

## Step 0 · 意图判定

精准问答（点查）。单主体单字段，答案有限，不追问。

## Step 1 · 查询解析

```
赛道：半导体
主体：森国科（口语）→ 待别名解析
doc_type：BP（推断：估值数据主要出现在 BP）
时间范围：不限
概念词：投后估值 / 估值 / 投后
检索类型：点查
```

## Step 2 · 定位

```
glob("datas-md/by_topic/半导体/**/BP/*.md") → 命中 75 份
```

## Step 3 · 三级检索

**P1 · 元数据层**

```
grep("森国科", "datas-md/by_topic/半导体/**/BP/*.md") → 2 份
  · by_topic/半导体/2022/BP/2022-05_BP_森国科SiC_v1.0.md
  · by_topic/半导体/2022/BP/2022-05_BP_森国科碳化硅SiC_v1.0.md
```

两份 `entity_key` 同为 `森国科sic`，且后者 `duplicate_of` 指向前者 →
**从属产物不计数，以主产物为准**。

**P3 · 证据核验**

| 字段 | `key_facts` 值 | 原文片段 | 判定 |
| --- | --- | --- | --- |
| 投后估值 | 10.2亿元 | 总股本2365万股 l 拟增发260万股 l 每股39元 l 融资金额1亿 l 投后估值10.2亿元 | ✅ 一致 |

## Step 5 · 输出

```markdown
## 结论
森国科 D 轮投后估值 **10.2 亿元** [S1]。

## 依据
1. 本轮为 D 轮融资，计划增发 260 万股、每股 39 元，融资金额 1 亿元 —— [S1]
2. 投后估值 10.2 亿元，与该轮融资额、每股价格自洽 —— [S1]

## 冲突与不确定
- 数值来源：`## 关键事实` 与 `## 原文证据` 一致，P3 核验通过。
- 库内存在 1 份重复产物（`2022-05_BP_森国科碳化硅SiC_v1.0.md`，
  `duplicate_of` 指向本文引用主产物，正文相似度 0.996），**未重复计入**。
- 补充：正文第 2 页给出工商全称「深圳市森国科科技股份有限公司」[S1]；
  该字段在 frontmatter 中为 `null`，此处取自正文，非结构化字段。

## 来源清单
| 编号 | 产物路径 | 主体 | 文档日期（来源） | 关键事实 | 原始文件 |
| --- | --- | --- | --- | --- | --- |
| S1 | by_topic/半导体/2022/BP/2022-05_BP_森国科SiC_v1.0.md | 森国科SiC | 2022-05（doc_text） | 投后估值 10.2亿元；融资金额 1亿；轮次 D轮 | datas/商业计划书/【半导体】森国科SiC -碳化硅项目商业计划书.pdf |

## 检索覆盖
- 检索路径：`datas-md/by_topic/半导体/**/BP/*.md`（命中 75 份）
- 关键词：`森国科` → 命中 2 份；实读 2 份
- 未纳入：`2022-05_BP_森国科碳化硅SiC_v1.0.md`（原因：`duplicate_of`，不重复计数）
- 未纳入：其余 73 份 BP（原因：主体不符，关键词未命中）
```

## 这个例子演示了什么

| 要点 | 体现 |
| --- | --- |
| P1 定位 | grep 主体名，2 份命中 |
| `duplicate_of` 处理 | 主产物引用、从属产物只声明不计数 |
| P3 核验 | `key_facts` 与 `原文证据` 对齐后才进答案 |
| 覆盖报告 | 说清读了 2 份、没读 73 份及原因 |
| 不臆造 | 全称来自正文且注明「非结构化字段」，没有编造 |
