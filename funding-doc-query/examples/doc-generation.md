# 正例 · 知识文档生成（含完整来源报告）

> 演示：意图分流 → 检索 → 落盘 `datas-generator/` → 来源报告三节齐全。

## 用户问题

> 帮我整理森国科的融资历史。

## Step 0 · 意图判定

原话「帮我整理」→ 既可以是清单式回答，也可以是一份可存档文档。
单主体、字段有限，**两种都成立**。按 `query-intent.md` 的模糊情形处理：

- 若用户已进入「要一份文档」的语境（如正在撰写投决材料），直接走生成，不追问；
- 否则**一轮 ≤3 问**确认形态。

本例按「生成」演示，并在文档开头声明判定理由，方便用户纠正。

## Step 2 · 定位

```
glob("datas-md/by_topic/半导体/**/BP/*.md")         → 75 份
grep("森国科", "datas-md/by_topic/半导体/**/BP/*.md") → 2 份
```

## 这个例子演示了什么

| 要点 | 体现 |
| --- | --- |
| 意图分流 | 「整理」按模糊处理；生成时说明判定理由，并附问答版兜底 |
| 落盘位置 | `datas-generator/`，且文档头声明「不参与后续检索」 |
| 去重 | 重复产物只在覆盖报告里声明，不重复引用 |
| P3 拦截 | 营收 1 亿元被认出是「上市门槛」而非经营数据，标未核实 |
| 报告三节 | 章节映射 / 原文片段 / 覆盖报告齐全，且外部来源节明确写「未联网」 |
| 不臆造 | 投资方没有轮次信息就写「无法对应到具体融资轮」 |
