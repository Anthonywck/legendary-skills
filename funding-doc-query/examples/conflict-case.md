# 正例 · 多源冲突并列（三源 + 一组干扰源）

> 演示：同一指标出现多个值时的正确处理——**并列 + 标注口径，不消解**。

## 用户问题

> 半导体光刻胶的国产化率是多少？

## Step 0 · 意图判定

精准问答（点查→实际是多源比较）。不追问。



## 这个例子演示了什么

| 要点 | 体现 |
| --- | --- |
| 不消解 | 三个值全部并列，没有「取最新」或「取平均」 |
| 口径标注 | 统计对象 / 年份 / 引用机构三项齐全，差异可说清 |
| 可信度提示但不下结论 | 给日期与 `date_source` 供用户判断，明确写「未择一」 |
| 干扰源隔离 | 面板光刻胶值单列，不混入主表 |
| `fs_mtime` 规则 | corrupt 那份的 fs_mtime 日期被显式排除在时效比较之外 |
| 未纳入说明 | 说明了被降级挡住的文件，而不是假装不存在 |
