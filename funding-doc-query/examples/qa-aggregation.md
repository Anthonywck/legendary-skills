## 用户问题

## Step 0 · 意图判定

精准问答（聚合）。答案是一份清单，不落盘成文档。

## Step 1 · 查询解析

```
赛道：新材料
主体：不限
doc_type：不限
时间范围：不限
概念词：—
检索类型：聚合
```

```
glob("datas-md/by_topic/新材料/**/*.md") → 命中 5 份
```

## 反例对照：这类问题常见的四种错法

| 错法 | 为什么错 |
| --- | --- |
| 只答「有光之科技、中熵科技…」不列全 5 份 | 用户无法判断是「只有这些」还是「只找到这些」 |
| 说「新材料赛道共 5 家公司」 | 5 份**文档**≠ 5 家公司；`欣奕华…` 与 `阜阳欣奕` 疑似同一家 |
| 把 `中熵科技项目` 与半导体的 `中熵科技` 合并成一条 | 跨赛道合并会掩盖赛道分类差异 |
| 不声明「无未纳入」 | 用户不知道是不是因为库内只有 5 份，还是因为只搜了 5 份 |

## 这个例子演示了什么

| 要点 | 体现 |
| --- | --- |
| 全覆盖 | 5 份 ≤ 8，全部实读，明确写「无未纳入」 |
| 计数口径 | 「5 份文档」而非「5 家公司」 |
| 不静默合并 | 疑似重复但 `duplicate_of: null` 时，并列 + 提示，不擅自合并 |
| 赛道边界 | `中熵科技` 跨赛道时保持分区，不跨库合并 |
